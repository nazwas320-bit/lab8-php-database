## Deskripsi
Project ini merupakan hasil pengerjaan praktikum PHP dan MySQL untuk membuat aplikasi pengelolaan data barang sederhana.

Aplikasi ini digunakan untuk mengelola data barang yang tersimpan di database MySQL, mulai dari menampilkan, menambahkan, mengubah, hingga menghapus data barang.

## Teknologi yang Digunakan
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- MAMP
- Visual Studio Code

## Fitur Aplikasi
1. **Menampilkan Data Barang** – Menampilkan seluruh data barang dari database.
2. **Menambahkan Data Barang** – Menambahkan barang baru.
3. **Mengubah Data Barang** – Memperbarui informasi barang.
4. **Menghapus Data Barang** – Menghapus data barang dari database.
5. **Upload Gambar Barang** – Menambahkan gambar pada setiap data barang.

## Cara Menjalankan Project

1. Pastikan MAMP sudah terinstal.
2. Aktifkan Apache dan MySQL melalui MAMP.
3. Simpan folder project di dalam direktori `htdocs`.
4. Buat database bernama `latihan1` melalui phpMyAdmin.
5. Buat tabel `data_barang` sesuai struktur database praktikum.
6. Sesuaikan konfigurasi database pada file `koneksi.php`.
7. Buka browser dan akses:

   http://localhost:8888/lab8_php_database/

## Konfigurasi Database

- Nama Database: `latihan1`
- Nama Tabel: `data_barang`
- Host: `localhost`
- Port MySQL: `8889`
